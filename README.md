# 🩺 Clinical Trials Explorer

A responsive web application that allows users to search and explore clinical studies based on different health conditions.

## ✨ Features

- 🔍 Search clinical trials by health condition
- 📋 Display clinical study titles, study IDs, and current status
- 🔗 View detailed information about each study
- 📱 Responsive design for different screen sizes
- ⚡ Uses JavaScript `async/await` to fetch API data
- 🛡️ Handles errors using `try/catch`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- ClinicalTrials.gov API

## 🌐 API Used

[ClinicalTrials.gov API](https://clinicaltrials.gov/data-api/api)

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Search for a health condition such as diabetes or asthma.
